Como configurar o repositório OneDrive
1. Cole a URL da pasta do SharePoint no campo OneDrive

11
Conectar OneDrive — Gestor
Obrigatório para sincronização dos relatórios
⚠️
Por que o Gestor precisa conectar?
O sistema usa o token Microsoft do gestor responsável pelo projeto para salvar os arquivos na pasta correta do OneDrive. Sem conexão, os relatórios ficam marcados como pendentes e são sincronizados automaticamente quando o gestor se conectar.
1
Procedimento (igual ao Admin)
O processo é idêntico ao do Admin — seção 7. Cada gestor deve fazer uma vez e o token fica salvo por 90 dias com renovação automática.
